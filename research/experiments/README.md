# Research Experiments

This directory houses modular experiment runners implementing the Phase-2 research matrix:

- `exp_classification_baselines.py`: Benchmark classifiers across rolling temporal folds.
- `exp_calibration_study.py`: Evaluate uncalibrated vs Platt vs Isotonic probability calibration.
- `exp_temporal_robustness.py`: Expanding-window distribution shift stability analysis.
- `exp_severity_study.py`: Conditional delay-severity estimation benchmarks.
- `exp_conformal_uncertainty.py`: Multi-level nominal coverage and sharpness evaluation.
- `exp_decision_utility.py`: Top-K operational prioritization and simulation utility.
- `exp_ablation_study.py`: Stepwise framework component ablation.
