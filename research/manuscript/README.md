# ORCA Research Track: Manuscript Package

This directory contains the complete academic manuscript, LaTeX sources, tables, figures, literature gap tracking, supplementary documentation, and peer review logs for the ORCA research project.

## Manuscript Information
- **Title**: *Calibrated Delay Risk and Conformal Severity Prediction under Temporal Distribution Shift in Pharmaceutical Supply Chains*
- **Primary Evidence Base**: 5-fold expanding-origin temporal evaluation with 90-day embargoes ($N=7,306$ shipments, $1,125$ delays).
- **Secondary Evidence Base**: Locked Registry Evaluation Set ($N=1,013$ shipments, $61$ delays), functioning as a secondary locked replication check.

## Directory Structure
- `manuscript.md`: Full academic manuscript in Markdown format.
- `manuscript.tex`: Complete, portable LaTeX article source.
- `tables/`: Machine-readable CSV data tables generated by frozen experimental scripts.
- `figures/`: High-resolution figures illustrating the framework, temporal evaluation, calibration reliability, CQR coverage, and decision utility.
- `references/LITERATURE_GAPS.md`: Systematic inventory of citation categories requiring formal external literature indexing prior to submission.
- `supplementary/SUPPLEMENTARY_PLAN.md`: Outline and detailed tables for the supplementary online appendix.
- `INTERNAL_PEER_REVIEW.md`: Multi-agent internal peer review audit.
- `REVISION_LOG.md`: Formal log of manuscript revisions addressing review comments.
